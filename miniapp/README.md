# 💛 Selora Prints — Telegram Serverless Next.js Mini App

A native Telegram Mini App (TMA) built with **Next.js 14**, **Tailwind CSS**, and **Telegram Serverless (`@tgcloud`)**.

---

## 🚀 Features

- **🛍️ Complete Printing Catalog:** 10+ custom print products (Business Cards, Flyers, T-Shirts, Hoodies, Ceramic Mugs, Stickers, Tote Bags, Banners, Badges, Brochures).
- **🎨 Interactive Customizer:** Live quantity pricing calculator, ready-made studio design selector, or custom artwork file upload with 1-by-1 upload guidance.
- **🚚 Ledeta Store Pickup & Doorstep Taxi Delivery:** Choice between free Ledeta store pickup and taxi dispatch (Yango / Feres / RIDE) with Google Maps GPS pin capture.
- **💳 50% Pre-payment Deposit:** Real-time 50% deposit calculation with 1-tap CBE (`1000056873639`) and Telebirr (`0906287728`) copy and receipt screenshot upload.
- **🔍 Live Order Tracking:** Instant order lookup (`SP-XXXX`) with a visual 4-step progress stepper (Deposit Review ➔ In Production ➔ Ready for Delivery ➔ Fulfilled).
- **🌐 Bilingual Support:** Instant toggle between English and Amharic (አማርኛ).
- **⚡ Telegram Native Serverless Architecture:**
  - Backed by Telegram's native V8 serverless isolate environment.
  - Zero external server bills during the Telegram Serverless launch period.
  - Built-in SQLite database for orders, products, and designs.

## 📋 Prerequisites

1. **A Telegram Bot** created via [@BotFather](https://t.me/BotFather).
2. **Node.js 18+** installed locally (Your machine currently has Node `v22.12.0`).
3. **Enable Serverless in BotFather:**
   - Open Telegram and message `@BotFather`.
   - Send `/mybots` and select your bot.
   - Tap **Bot Settings** ➔ **Serverless** ➔ **Enable**.

## 🛠️ Local Development (Next.js)

To run the Next.js frontend locally with hot-reloading:

```bash
cd miniapp
npm run dev
```

Open `http://localhost:3000` in your browser. The app includes automatic dev-mode fallbacks so you can test all screens and workflows even outside Telegram.

---

## 🚀 Deployment to Telegram Serverless

### Step 1: Link your Bot Token
From the `miniapp/` folder, run:
```bash
npx tgcloud login
```
Paste your Bot API token provided by BotFather.

### Step 2: Build & Push
Deploy your Next.js Mini App frontend and Serverless backend in one command:
```bash
npm run deploy
```
*(This automatically runs `next build` to generate the production static bundle and uploads it to Telegram Serverless via `tgcloud push`)*.

### Step 3: Link the Mini App in BotFather
1. In `@BotFather`, send `/newapp`.
2. Select your bot, enter the title `Selora Prints`, description, and upload a thumbnail.
3. When asked for the Web App URL, use the URL generated by `tgcloud push` (or `https://app<bot_id>.tgcloud.ai`).
4. To add a permanent button in the chat, send `/setmenubutton` in `@BotFather`, choose your bot, and enter `🛍️ Open Store` with your app URL.
